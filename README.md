# David Meneses's Portfolio

An interactive portfolio of original illustrations (Personal) and university projects (Professional), with a menu-style interface, zoom transitions and a live clock.

It is a static site: `index.html` plus the `img/` folder. No build step and no dependencies.

To run it locally, open `index.html` in a browser, or serve the folder (for example `python3 -m http.server`).
